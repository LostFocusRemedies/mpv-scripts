# MPV scritps

`excerpt.lua` was taken from Morrolinnux repo and edited to my taste. https://github.com/morrolinux
I used that to learn the api, and lua a bit, and went on to make my own scripts, to save time. 

## installation: 

On Windows, just place them in : `C:\Users\User\AppData\Roaming\mpv.net\scripts\`
On Linux is probably way easier, somewhere in `~/.config/mpv/scripts` but double check that.
